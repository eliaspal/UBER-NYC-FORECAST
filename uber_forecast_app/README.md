# NYC Hourly Demand Forecast

Same-day / next-day hourly demand forecasting on the Uber NYC pickups dataset
(Apr-Sep 2014, ~4.5M trips). Built as a portfolio piece for logistics &
scheduling roles.

## What it does

- Forecasts the next 24h or 48h of pickups on an hour-by-hour basis
- Compares the forecast against the actual future to show real accuracy
- Breaks the forecast down into morning / afternoon / night shifts
- Flags hours where demand is significantly above the historical baseline

Live demo: _add Streamlit Community Cloud URL after deploy_

## Method

A hybrid model that splits the signal in two:

| Component | Model | Captures |
|---|---|---|
| Trend | LinearRegression | Long-term growth |
| Seasonality + serial dependence | XGBoost on residuals | Hour-of-day, day-of-week, lags (1h / 24h / 168h), rolling means |

Cross-validated with walk-forward (5 weekly test windows): mean RMSE 152.6,
mean R squared 0.953. The linear baseline alone scores RMSE 746.7, so the
hybrid cuts error by ~80%.

## Local run

```bash
pip install -r requirements.txt
python train_model.py     # one-time, produces model.pkl
streamlit run app.py
```

## Files

- `data_loader.py` - loads the six monthly CSVs, cleans, aggregates to hourly
- `forecast.py` - feature engineering + `HybridForecaster` with recursive prediction
- `train_model.py` - trains once and pickles `{forecaster, history}`
- `app.py` - Streamlit UI
- `model.pkl` - serialized model + history (1.4 MB, regenerated by `train_model.py`)

## Data source

[FiveThirtyEight Uber Pickups in New York City](https://www.kaggle.com/datasets/fivethirtyeight/uber-pickups-in-new-york-city)
